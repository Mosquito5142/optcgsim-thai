# หน้าดาวน์โหลดม็อดการ์ดภาษาไทย OPTCGSim (Next.js)

เว็บสแตติกที่สร้างด้วย Next.js (App Router) + Motion ธีม **แผนที่สมบัติ / ผจญภัยโจรสลัด** มีแอนิเมชันตามการเลื่อนหน้า
สร้างไฟล์ HTML/CSS/JS ล้วนใน `out/` นำไปวางที่ไหนก็ได้ (GitHub Pages, Cloudflare Pages, Netlify ฯลฯ)

## ธีมและแอนิเมชัน

ภาพทั้งหมดวาดเองเป็น SVG/CSS ใน `src/components/Art.tsx` และ `src/app/globals.css`
(เข็มทิศ เรือใบทั่วไป หีบสมบัติ ตราประทับขี้ผึ้ง คลื่น เงาโจรสลัดทั่วไป สมอเรือ กากบาท X)

- เชือกบนสุดยาวขึ้นตามการเลื่อน มีเรือเล็กแล่นไปตามเชือก (ขอบล่างของจอ) และแถบหัวเว็บแบบไม้กระดานมีเข็มทิศหมุนตามการเลื่อน
- Hero: ดาว พระอาทิตย์ คลื่น ข้อความ และม้วนแผนที่ตัวอย่างก่อน-หลังเคลื่อนด้วยความเร็วต่างกัน (parallax) มีเส้นประเส้นทางวาดตัวเองไปหาเครื่องหมาย X
- ตัวเลขนับขึ้น (การ์ด / บรรทัดข้อความ) เมื่อเลื่อนมาถึง
- หัวข้อมีเส้นประวาดตัวเอง การ์ดกระดาษเก่าพร้อมตราประทับเลื่อนขึ้นมาทีละใบ
- ภาพหน้าจอเป็นรูปถ่ายติดกระดานไม้ (หมุด/เทป) ลอยเลื่อนช้า-เร็วสวนทางกัน
- ปุ่มดาวน์โหลดเป็นหีบสมบัติที่ฝาเปิดเมื่อชี้/โฟกัส/กด ขั้นตอนติดตั้งเป็นเกาะต่อกันด้วยเส้นประ เมื่อถึงขั้นสุดท้ายกากบาท X ปรากฏ
- FAQ เป็นโน้ตกระดาษขอบฉีก บันทึกอัปเดตเป็นสมุดบันทึกประจำเรือ ส่วนสนับสนุนเป็นโปสเตอร์
- ถ้าเครื่องผู้ใช้ตั้ง "ลดการเคลื่อนไหว" (prefers-reduced-motion) แอนิเมชันที่เคลื่อนที่จะถูกปิดอัตโนมัติ

## ห้ามเพิ่ม (กันปัญหาลิขสิทธิ์/เครื่องหมายการค้า)

ธีมนี้ "ได้กลิ่นผจญภัยโจรสลัด" แต่ต้องไม่ลอกของจริงจาก One Piece หรือ Bandai ห้ามเพิ่มสิ่งต่อไปนี้:

- ตัวละคร หน้าตา หรือเงาของตัวละครจริง (ลูฟี่ ฯลฯ) รวมถึงหมวกฟางหรือสัญลักษณ์เฉพาะตัว
- ธงโจรสลัดของกลุ่มใดกลุ่มหนึ่งในเรื่อง หรือโลโก้ One Piece / Bandai / OPTCG
- ดีไซน์เรือที่เป็นของเรื่องโดยเฉพาะ (เช่น เรือหัวสิงโต/แกะ) ใช้ได้เฉพาะเรือใบทั่วไปที่ไม่มีเอกลักษณ์
- ชื่อเฉพาะในเรื่อง: ผลปีศาจ, Log Pose, Grand Line, Straw Hat, Marines ฯลฯ และภาพหรือฟอนต์ที่ลอกจากโปสเตอร์ค่าหัวจริง
- ภาพการ์ดเต็มใบ ภาพจากอนิเมะ/มังงะ เพลง หรือเสียงจากเรื่อง

ถ้าอยากเพิ่มลูกเล่นใหม่ ให้วาดเองจากรูปทรงพื้นฐาน (เข็มทิศ แผนที่ หีบ คลื่น ฯลฯ) และใช้ชื่อกลางๆ ของโจรสลัดทั่วไป

## รันในเครื่อง

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # สร้างเว็บสแตติกไว้ที่ ./out
npm run preview    # เปิดดู ./out
```

## สิ่งที่ต้องแก้เอง: ไฟล์เดียว `src/config/site.config.ts`

- ลิงก์ดาวน์โหลด Windows / Android / iOS (+ ลิงก์สำรอง) ลิงก์ Ko-fi ช่องทางติดต่อ และรูป QR พร้อมเพย์ (วางรูปไว้ใน `public/assets`)
- ช่องที่เว้นว่างไว้ ปุ่มจะขึ้นว่า "ลิงก์ดาวน์โหลดยังไม่พร้อม" และกดไม่ได้
- ปุ่ม "เครื่องมือแปลงไฟล์ Android" ปิดไว้ (`enabled: false`) จนกว่าเครื่องมือจะเสร็จ

## ข้อมูลที่สร้างอัตโนมัติ (อย่าแก้มือ)

`src/data/site-data.json` และ `public/assets/cmp-*.webp` (ขนาดไฟล์ SHA-256 วันที่ จำนวนการ์ด รูปตัวอย่างก่อน-หลัง)
สร้างจากโปรเจกต์ `thai_cards` ด้วยคำสั่ง

```bash
python build_site.py --next C:\path\to\optcgsim-thai-site
```

รันทุกครั้งหลังสร้างไฟล์ติดตั้ง/APK/IPA ใหม่ ไม่งั้นค่า SHA-256 บนเว็บจะไม่ตรงกับไฟล์จริง

## เผยแพร่ด้วย GitHub Pages (ฟรี)

1. สร้าง repository บน GitHub แล้ว push โฟลเดอร์นี้ขึ้นไป (branch `main`)
2. ใน Settings > Pages ตั้ง Source เป็น **GitHub Actions**
3. push ครั้งต่อไปจะ build และเผยแพร่เองจาก `.github/workflows/deploy.yml`
   (ใช้ `NEXT_PUBLIC_BASE_PATH=/<ชื่อ repo>` ถ้าใช้โดเมนของตัวเอง ให้ลบบรรทัดนั้นออก)
4. ฝากไฟล์ `.exe` ไว้ที่ Releases ของ repo เดียวกัน แล้วนำลิงก์ไปใส่ใน `site.config.ts`

## หมายเหตุ

- หน้านี้ไม่ใช้ภาพการ์ดเต็มใบ ตัวอย่างก่อน-หลังตัดเฉพาะกล่องข้อความ
- ไฟล์ APK/IPA มีรูปการ์ด Bandai อยู่ข้างใน ถ้าจะแจกสาธารณะควรพิจารณาความเสี่ยงลิขสิทธิ์
- ฟอนต์ (Prompt, Chonburi, Mali) ถูกดาวน์โหลดและฝังเข้าไปในไฟล์ตอน build ผ่าน `next/font` ไม่ต้องเรียก Google ตอนผู้ใช้เปิดเว็บ
